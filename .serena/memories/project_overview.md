# Project Overview

This is a static website for a law firm called "FL y Asociados" located in Los Ángeles, Biobío region, Chile. The site is built using Astro for optimal performance and SEO, with Tailwind CSS for styling, TypeScript for type safety, and PHP with PHPMailer for contact form handling.

## Purpose
- Professional website for a law firm
- Showcase services, team, testimonials
- Contact form with email functionality
- Responsive design for all devices

## Tech Stack
- **Frontend**: Astro (static site generator), Tailwind CSS, TypeScript
- **Backend**: PHP script for contact form processing
- **Email**: PHPMailer with SMTP authentication
- **Security**: reCAPTCHA v3 for form protection

## Key Features
- Modern, responsive design with corporate colors (dark blue #1f2c3d, gold #c5a47e)
- SEO optimized with structured metadata
- Robust contact form with validation and backup
- Team profiles, services, testimonials sections
- News/blog section

## Architecture
- Static output from Astro
- PHP script for form handling (server-side)
- Hosted on shared hosting with FTP deployment
